Inside PatchBandit

A detector returns boxes, classes, and confidence scores. Its weights and gradients stay hidden.

What counts as success?

The target is the highest-confidence class in the clean image. On the patched, untransformed image, both conditions must hold:

Confidence drop ≥ 0.25 and Remaining confidence ≤ 0.10

Confidence is the maximum score for that class across detected boxes, or zero if the class is absent. Suppressing that class does not mean every object disappears. Expectation over Transformation (EOT) tests transformed views separately; an EOT average is not a replacement for this plain-image test.
